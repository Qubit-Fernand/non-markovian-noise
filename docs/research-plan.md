# 非马尔可夫噪声研究方案

日期：2026-09-21。本文保存项目初步研究设计；实际完成的原型见[数值模拟报告](simulation-report.md)。

## 核心问题

先检验“保留跨门时间相关性的模型能否更准确预测未参与拟合的电路”，得到证据后再研究误差缓解。

单门通道测得准确，不保证完整电路等于独立单门通道的组合。环境可能记住前面的控制历史。这一差异比单纯从两个比特增加到四个比特更适合作为研究主线。

## 模型与假设

| 模型 | 所保留的信息 | 研究问题 |
|---|---|---|
| M0：Markovian Lindblad/Pauli | 无跨门环境记忆 | 常用模型预测到什么程度？ |
| M1：quasi-static | 整条电路共享的随机失谐 | 极慢漂移能否解释主要差异？ |
| M2：经典有色 Gaussian 噪声 | 连续时间相关性 | 动态记忆是否必要？ |
| M3：量子浴与 HEOM | 量子浴相关函数及环境反作用 | 超越经典噪声的处理是否值得？ |

最初采用局域独立 Z 型耦合，将空间相关性、泄漏等留作后续扩展。HEOM 是给定环境模型的求解器，不保证所选环境模型更符合硬件。M2 与 M3 需要匹配谱的明确部分、频带、温度与控制才能公平比较。

## 电路设计

1. 单比特 Ramsey、echo、X/Y/XY 有限脉冲序列：验证实现、校准模型。
2. 两比特连续 CR 门、恒等门块与等待时间扫描：定位跨门记忆。
3. 三至四比特 mirror circuits、不同深度与门序：检验未见电路预测。
4. 收益明确后扩展到短程 Ising 模拟电路，观测磁化与两点关联。

比较尽可能匹配总时长、门数但时序不同的序列。X/Y 差异应更换初态核验，不能把某一初态下的差异视为普遍门性质。

## 核心消融：保留记忆与重置环境

对相同参数和控制，分别连续传播环境，以及在门边界恢复初始环境条件。

$$\Delta_{\rm mem}(O)=\langle O\rangle_{\rm continuous}-\langle O\rangle_{\rm reset}.$$

这是一项数值诊断，不是假设硬件上可以随意重置环境。HEOM 必须跨门传递完整辅助层级；仅相乘每个门独立计算的 HEOM 通道可能丢掉目标效应。

理论起点是平稳 Gaussian 纯退相干：

$$W(T)=e^{-\chi(T)},\quad \chi(T)=\frac12\int_0^Tdt\int_0^Tds\,y(t)y(s)C_\xi(t-s).$$

其中 $y(t)=\pm1$ 是理想翻转脉冲的符号函数。按门划分积分域可以分离门内与跨门项。有限脉冲和 CR 控制中的不对易算符需要进一步处理。

## 验证标准

各模型使用同一批校准数据，冻结参数后预测未参与拟合的电路、深度和等待时间。主要报告观测量 RMSE、统计不确定度、计算时间和校准成本。

收敛数值结果用于验证给定模型下的近似误差；留出硬件数据用于判断物理模型是否解释实验。用 HEOM 生成数据再证明 HEOM 拟合最好，不能代替硬件验证。

可事先约定推进门槛：在多个测试电路族上稳定降低预测误差至少两倍，收益超过统计及数值误差，并可通过记忆消融解释。十倍改善可以作为强结果，但不宜是唯一门槛。若 M1 或 M2 已达到 M3 的精度，优先研究便宜模型的适用范围。

## 后续误差缓解

研究用校准模型预测哪些 folding 序列可靠，以及噪声放大失配带来的外推偏差。比较理想幅度放大、local folding、global folding 和模型选择的时序，并按固定总 shots 比较均方误差。

时间相关噪声下 folding 的谱失配已有直接研究，不能单独作为新颖性主张；参考 [Schultz et al., PRA 106, 052406](https://arxiv.org/abs/2201.11792)。若转向 PEC，还需比较 [Wang and Li, arXiv:2501.05019](https://arxiv.org/abs/2501.05019)。

## 原定四周可行性安排

| 阶段 | 交付 |
|---|---|
| 第 1 周 | 统一谱、单位和截止约定；验证解析极限与代表性脉冲结果 |
| 第 2 周 | 两比特连续/重置环境对照，扫描重复次数与等待时间 |
| 第 3 周 | 冻结参数，预测三比特测试电路，比较精度与成本 |
| 第 4 周 | 总结适用范围，决定是否进入 folding 或器件实验 |

目前已完成通用求解原型和数值一致性检查，不等于已完成论文参数复现、两比特 CR 验证或硬件模型选择。
