# 已经跑出了什么？

本页汇总已有合成数值实验，按 [Overview](overview.md) 的计算链组织。2026-11-19 只整理文档，没有重新运行下列实验。不同包、不同噪声模型和不同机器的数字不能直接合并为一个性能基准。

## HEOM 与传播：先验证动力学

旧 `nmnoise` 保存了经典噪声的 dense／空间 MPS 轨迹，以及量子浴 HEOM／显式浴对照。2048 条轨迹主运行见 [validated/summary.json](../results/validated/summary.json)，模型和误差检查见[原模拟报告](archive/simulation-report.md)。它与新包的经典 Hermite HEOM 模型不同。

`heom_spp_cpu` 的 [2026-11-11 CPU 验证记录](../heom_spp_cpu/docs/cpu-validation-20261111.md)已经包含 MPO 生成元、TDVP、并行和静态积分对照。下面只摘录其中一组历史结果：Windows i7-8700，一比特、两个三级 OU 坐标、三层、最大步长 0.1 ns。

| 比较 | SPP 联合概率 L2 差 |
|---|---:|
| RK4 对同层级稀疏参考 | 2.5383e-9 |
| TDVP 对同层级稀疏参考 | 2.5381e-10 |
| TDVP 双进程对单进程 | 4.1510e-16 |

此记录随后还有静态模型和模块拆分的验证，不能只用最早的测试数代表当前版本。其详细大结果目录未随源码包携带；本页引用的是保存的验证报告，不声称本机已重新核对那些原始数组。

## SPP 构造：时间 MPS 能避免完整表

2026-11-04 的四比特、四层有限控制例子，只在 q0 上放一个 OU 模，每模保留三级，RK4 最大步长 0.1。结果见 [MPS 运行](../results/spp_tn_ising4_mps_20261104/README.md)、[对照数据](../results/spp_tn_ising4_mps_20261104/comparison.json)和[稀疏参考](../results/spp_tn_ising4_dense_20261104/summary.json)。

| 指标 | 结果 |
|---|---:|
| 完整错误历史数 | $256^4=4,294,967,296$ |
| 输出 MPS 系数数 | 6144 个复数，complex128 为 96 KiB |
| 完整表若按 float64 保存 | 32 GiB |
| MPS 与同层级参考的联合 L2 差 | 2.4683933e-5 |
| 最大单层边缘差 | 1.0237605e-5 |
| MPS 归一化误差 | 1.7763569e-15 |
| MPS 时间键／参考时间键 | (3,3,3)／(2,2,2) |

**可展示的结论是避免了完整历史枚举，并用 TN 收缩做了联合张量对照。** 96 KiB 是最终表示大小，不是峰值内存；低层级单模例子不证明多模、物理收敛后仍有小秩。没有核验完整历史非负性，也没有该四比特分布的采样或 PEC 精度结果。

这两次运行约用时 213 s 和 10 s，且并行启动，只是实现检查。当前例子中 MPS 原型更慢，不能宣传加速。

## 预测与缓解：单比特同时有 PEA 和 PEC

[2026-11-04 完整记录](../results/spp_tn_20261104_final/README.md)为一比特、三层、一个 OU 模、五级截断的已知模型实验，包含 [summary.json](../results/spp_tn_20261104_final/summary.json)、源码快照及 shots 样本。

| 响应 | 期望值 | 与理想值之差的绝对值 |
|---|---:|---:|
| 理想 | 0.961055438311 | — |
| 含噪 | 0.794723643390 | 0.166331795 |
| 独立模型 PEC | 0.981230946900 | 0.020175509 |
| 相关模型 PEC | 0.961055438309 | 约 1.4e-12 |
| PEA 二次外推 | 0.956073149015 | 0.004982289 |

独立模型对含噪响应的预测为 0.778382991126，说明在这一例子中忽略相关性已经影响预测。PEA 使用增益 1、2、3 再外推，保留了残余偏差。相关 PEC 的接近精确抵消是**同一截断模型内的代数检查**，不能作为真实噪声模型误差为零的证据。

有限 shots 的 PEC 为 $0.961462\pm0.005237$（20,000 shots，一个标准误差），$\Gamma^2=1.47297145$。误差条不包含模型学习不确定度。变分逆与稠密 Walsh 逆的 L2 差约 1.38e-12。

## 哪些误差已分开检查？

同一单比特记录将层级、步长、内部键和时间键分开扫描：

| 检查 | 概率 L2 误差 | 参考 |
|---|---:|---|
| 层级 3／5／7 | 8.22e-4／3.47e-6／7.04e-9 | 层级 10 |
| RK4 步长 0.2／0.1／0.05 | 2.66e-6／3.01e-7／1.94e-8 | 同为五级的稀疏指数 |
| 内部键 1／2 | 9.59e-2／6.42e-3 | 同层级参考；强截断出现非法概率 |
| 时间键 1／2 | 2.97e-3／1.33e-5 | 原时间张量的截断对照 |

没有静默修复强截断的分布。单比特未进一步压缩的 MPS 有 92 个系数，超过其完整表的 64 项；该例验证计算链和误差，不能用来展示存储收益。Conda 环境重跑的差异记录见 [environment_comparison.json](../results/spp_tn_conda_20261104/environment_comparison.json)。

## CPU 优化验证到哪里？

上述 CPU 报告还记录四比特前两学习层、q0 单 OU 模、两级截断的首核收缩优化：同粗步长、双进程下，通用实现约 122.14 s，稀疏通道实现约 16.94 s，联合概率差 1.20e-15。同层级稀疏参考约 11.91 s。

约 7.2 倍是这一实现优化的本地单次结果，不是 TDVP 相对其他求解器的普遍优势，也不代表服务器并行效率。只记录了小规模 1／2 worker 检查，没有 52 worker 或 GPU 结果。两级截断不是物理收敛证据。
