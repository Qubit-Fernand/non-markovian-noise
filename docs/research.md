# 接下来要解决什么？

研究流程见 [overview.md](overview.md)，已有证据见 [experiments.md](experiments.md)。本页统一维护任务；旧 proposal 的任务表属于历史记录，不再作为当前进度。

## 核心问题与范围

给定控制线路和噪声模型，达到指定 SPP 精度需要多大的 HEOM 层级、内部键和时间键？能否在不枚举全历史的情况下控制构造成本，并在预测或缓解中体现保留记忆的价值？

第一阶段聚焦已知经典高斯噪声下的前向计算。器件噪声辨识、量子浴推广、CZ 泄漏建模和真机缓解是后续方向，各自需要独立输入与验证。文献框架提出的多比特目标是研究设想，不代表已完成实现或已确定本阶段验收规模。

## 按流程图推进

| 环节 | 已有基础 | 下一项交付物 |
|---|---|---|
| 控制 + 噪声输入 | 有限脉冲、分层、静态／OU 配置及原生 sqiSWAP 示例 | 固定比较线路、单位、噪声参数和误差目标，保存不可混用的配置 |
| HEOM | 经典 Hermite 层级及小规模稀疏指数参考；旧包另有量子浴对照 | 层级截断收敛与噪声模型适用范围 |
| 层级 MPS + MPO／TDVP | `spp_tn` 为 RK4；`heom_spp_cpu` 已有 MPO／TDVP 和局部 CPU 优化 | 对目标模型复核生成元作用、传播精度、键维数与步长 |
| Pauli 响应 → 时间 MPS | gate-after、开放 ADO、Walsh 及逐层压缩 | 端到端参考对照，分别量化组装与时间截断误差 |
| 预测／PEA／PEC | 单比特完整示例、独立层对照 | 在收敛模型上检查留出预测与缓解偏差、采样成本 |
| 扩规模与性能 | 小规模串行／双进程记录 | 同精度 CPU 基准，再评估 GPU 可行性 |

建议以 `heom_spp_cpu` 的现有 MPO／TDVP 为验证入口，保留 `spp_tn` 的 RK4 与各包的稀疏参考进行交叉核验。两包的模型和参数先逐项对齐，不因为名称相同就默认等价；本轮文档整理不合并代码包。

## 近期任务与验收

1. [ ] **固定输入与结果身份。** 明确理想门、实际脉冲、层划分、gate-after、位序、单位与噪声参数。扫描复用前检查配置、基线分析前检查线路的两项保护已实现，见[修复记录](../heom_spp_cpu/docs/known-issues.md)。研究层面的比较协议与误差目标仍需确定；更换模型或同名组参数时使用新目录。
2. [ ] **复核生成元与 TDVP。** 检查 MPO 作用与独立稀疏生成元一致，检查非幺正传播的全部 ADO，而非只看根态；对照稀疏指数和收敛 RK4。记录局部 Krylov 容差、步长、初始秩与键增长策略，不自动归一化层级 MPS。
3. [ ] **完成目标模型的 HEOM → SPP 收敛。** 分别扫描层级数、积分步长、HEOM 内部键、响应组装键和时间键；报告联合张量差、边缘差、虚部、归一化和可检查的非负性。小模型直接枚举核验；大模型无法证明全历史非负时明确保留这一限制，不把归一化当作替代。
4. [ ] **验证预测及缓解。** 静态经典噪声用独立积分参考，有限相关时间用合适的独立动力学对照；比较完整相关模型、边缘乘积及重置基线。报告 PEA 外推偏差、PEC 逆残差、观测量偏差、$\Gamma$ 和采样误差，区分同模型代数抵消与物理精度。
5. [ ] **增加模式数与线路长度。** 从一比特多模式和已有四比特单模例子出发，逐步增加模式和层数。保存误差—键维数—成本曲线；强截断失败同样保留。空间系统腿仍为指数规模，不能只报告时间 MPS 的存储优势。
6. [ ] **再做 CPU／GPU 优化。** 对已通过精度验收的配置剖析收缩、局部求解、QR／SVD、探针传播和组装成本；控制进程与 BLAS 线程。GPU 先检查 complex128、分解和局部求解支持，再决定后端与批处理，不能仅切换 TensorCircuit 后端就宣称完成迁移。

每个比较在运行前明确目标容差和参考误差，不以“图看起来一致”验收。性能比较必须采用相同物理模型和达到相同精度的设置，报告墙钟时间、峰值内存／显存、版本、硬件与重复次数；GPU 计时同步，分开报告预热。已有 CPU 优化可以保留，但不得替代目标模型的收敛验证。

## 后续：测控、学习与硬件

- [ ] 将器件 schedule、真实波形及误差预算接入输入；对 OU／准静态／其他谱模型做留出比较，并考虑参数不确定度。
- [ ] 从受控一比特相关噪声正对照开始，明确可用测量、SPP 的可辨识范围及学习 shots 成本，再扩展未知噪声学习。
- [ ] 检查逐层 SPL 模型在哪些控制、深度和历史下失效。非指数衰减本身不等于多时刻记忆或 CP 不可分性的证明。
- [ ] 在原配对脉冲扫描基础上纳入控制／读出误差和硬件波形，做留出预测；旧方案见[配对实验 proposal](archive/paired-pulse-proposal.md)。
- [ ] 决定器件与原生门后，再落实 CZ／CR 等门的噪声来源、泄漏与量子浴范围。当前两能级系统腿不能直接描述三能级泄漏。
- [ ] 研究有噪声 twirling／修正操作、可验证非负的表示，以及更大规模 signed-PEC 采样；近奇异逆和高 $\Gamma$ 仍可能使缓解不可行。

这些任务尚无真机完成记录。旧量子浴的层级 MPS／TEMPO 与可扩展空间表示也不视为当前经典路径已经完成的功能。
