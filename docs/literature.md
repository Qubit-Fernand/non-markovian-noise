# 文献怎样接到这条研究主线上？

本页将四份用户提供的导读／调研及原有笔记收拢为一条叙述：**测控给出噪声模型 → HEOM 计算记忆动力学 → 张量网络构造 SPP → 预测与缓解**。计算流程与术语定义见 [overview.md](overview.md)，任务以 [research.md](research.md) 为准。

本轮是材料整理，没有重新逐篇精读或验证原稿中的创新性判断。下文区分已记录的文献结论、项目实现与待研究设想；完整推导和待核实项保留在原稿中。论文 PDF 与逐篇主题表统一放在项目同级 [Zotero/README.md](../../Zotero/README.md)，不在这里复制表格。独立克隆代码时，本地 Zotero 目录不可用，可使用文中的 arXiv 链接。

## 1. 为什么从 PEC 采样讲起？

概率误差抵消（PEC）最终需要可执行的随机修正操作及有符号权重。实验不是直接“运行一个负概率门”，而是按修正系数的绝对值抽样，再把符号和总权重放入观测量估计。

这些采样权重依赖噪声模型，所以“如何学习模型”和“如何使用模型抵消”必须分开。SPL 路线用少量 Pauli–Lindblad 生成元参数描述噪声，学习特定 Pauli 衰减，再构造修正。参见 [SPL-PEC](https://arxiv.org/abs/2201.09866) 与 [SPL 学习技术](https://arxiv.org/abs/2311.15408)，操作层面的解释见[主线导读原稿](archive/literature/05_主线导读_从PEC采样到SPP.md)。

时间相关噪声可能让同一层的有效响应依赖此前的控制和噪声历史。此时，单层边缘正确仍不足以保证整条线路的预测正确；这正是从逐层模型走向多时刻对象的动机。

## 2. SPP 改变了什么对象？

SPP 保存各层 Pauli 错误的联合分布，而非仅保存每层的边缘。相同的单层噪声可以有独立、同向或其他时间关联，从而产生不同的线路响应。[SPP 论文](https://arxiv.org/abs/2603.05474)提供多时刻 Pauli 过程的语言；本项目研究如何从给定噪声动力学构造这一对象，并用时间 MPS 保存它。

这里有三种容易混淆的问题：

- 单层 Pauli 通道是否能由非负速率的 Markov 半群生成？
- 一族约化动力学是否 CP 可分？
- 多时刻实验是否存在不能由逐层独立模型描述的历史关联？

它们不能互相替代。尤其[单快照 Pauli 通道研究](https://arxiv.org/abs/2602.13145)中的非马尔可夫性不直接给出整条 SPP，也不能把负拟合速率直接解释为已辨识的跨门记忆。定义与例子见[模型层级笔记](archive/pauli-noise-model-hierarchy.md)。

## 3. HEOM 接在模型和 SPP 之间

给定噪声相关函数、耦合与控制波形，可以先解动力学，再构造逐层 Pauli 响应。HEOM 用辅助层级携带记忆，适合研究有限门时长内控制和噪声同时作用的情形。[超导门与经典非马尔可夫噪声](https://arxiv.org/abs/2509.07693)是相关动力学背景。

这条前向路线回答的是“假设模型已知，会得到怎样的跨层关联”。它尚未回答“有限硬件数据能否唯一识别该模型或整个 SPP”。[Wang–Li 的非马尔可夫缓解](https://arxiv.org/abs/2501.05019)也需要按其已知浴相关函数与近似范围理解，不能据此省略本项目的噪声学习工作。

文献框架将工作分为测控、HEOM–SPP、学习与缓解三部分。当前可以优先验证中间的前向链；两端通过明确的模型参数、测量设置和误差预算对接。详见[课题框架原稿](archive/literature/05_课题框架_测控_HEOM-SPP_学习与缓解.md)。

## 4. 为什么需要张量网络？

完整错误历史的数量随时间层数指数增长。MPS 允许按保留的记忆维数组织联合概率，MPO 可以表示 HEOM 生成元，TDVP 则负责层级 MPS 的时间推进；这些工具的不同职责见 Overview。

[MPO 量子误差缓解](https://arxiv.org/abs/2201.00752)与[张量网络读出误差](https://arxiv.org/abs/2606.25974)都说明张量网络可用于噪声和缓解对象，但对象、时间结构与逆问题不同。不能因为都出现 MPO，就把它们等同于本项目的 HEOM 生成元 MPO 或 SPP 时间 MPS。

因此，项目需要报告三项独立证据：动力学近似是否收敛，SPP 是否在目标精度下可压缩，以及预测／缓解是否受益。低秩的正向过程并不保证低秩的逆或可接受的 PEC 采样成本。

## 5. 和已有大规模缓解工作的关系

此前对 [IBM 2607.25998](https://arxiv.org/abs/2607.25998) 的核对记录区分了 SPL-PEC 主流程与附录 F.2 的准静态相关拟合。后者用于讨论残余偏差，并不等于论文完成了一般 SPP 的学习与求逆。项目应把它作为模型失配与基线选择的参照，详细出处见[专项核对](archive/ibm-2607-25998-review.md)。

用户补充的 [2609.13108](https://arxiv.org/abs/2609.13108)也使用时空噪声与缓解语言。其逻辑错误、后选择和时空 SPL 语境需要与本项目的浴记忆问题区分；它不能自动作为一般 HEOM–SPP 学习已解决的证据。PDF 入口仍归 Zotero 管理。

## 6. 测控与 CZ 噪声这一支

[Oda 协议及 CZ 专题原稿](archive/literature/05_Oda协议与CZ门噪声源_调研.md)围绕 [2412.16092](https://arxiv.org/abs/2412.16092)讨论稀疏物理噪声参数、测控协议以及从 CR 到 CZ 的适用边界。候选问题包括失谐、控制畸变、TLS 与泄漏；是否属于项目的主要噪声，需要结合器件和实验数据判断。

当前代码中的原生 sqiSWAP 分解不能被称为 CZ 噪声模型，二能级系统也不能直接验证泄漏。原稿中的“未找到相关工作”等说法是检索记录，不能提升为已经证明的新颖性结论。
