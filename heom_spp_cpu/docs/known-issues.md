# 已知问题与待解决事项

以下问题在 PR #1 合并前的代码审查中发现，目前尚未修复。使用相关功能时请留意。

## 收敛扫描可能复用不同参数的旧结果

`scripts/scan_convergence.sh` 默认的结果目录只包含 Trotter 步数。脚本依据 `summary.json` 是否存在判断参考解或扫描组是否已完成，并不核对现有结果的参数。

因此，在同一结果目录下修改 `SIGMA`、`EXAMPLE`、`PULSE_ARGS` 或参考解的 `NODES` 后重新运行，可能继续使用旧结果；新增的扫描组也可能被拿去与旧参数的参考解比较，导致错误的收敛判断。

临时处理：每组物理参数和参考解设置使用不同的 `ROOT`，并检查各结果的配置。待解决：复用结果前核对配置，不匹配时明确报错或要求使用新的结果目录。

## 基线分析未核对线路内容

`heom_spp.analyze` 的 `--baseline` 当前只检查 SPP 的维度，未核对基线与被分析结果的线路定义。不同线路只要比特数和层数相同，就可能被接受并用于 ZNE 和 PEC，产生没有提示的误导性结果。

临时处理：使用基线前手动核对两个结果的 `layers.json`，确保线路及层划分一致；噪声模型可以按比较目的不同。待解决：加载基线时校验线路和层定义，遇到不匹配时拒绝分析并说明原因。
